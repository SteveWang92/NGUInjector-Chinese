# NGUInjector 中文版

[English README](README.md)

NGUInjector 是面向 Steam 版 **NGU IDLE** 的自动化注入器。本项目提供中文设置界面和中文提示，并在原项目基础上增加了自己的功能，配置文件与原项目兼容。

如果想了解各功能的触发条件、优先级、换装恢复和常见卡住原因，请阅读 [中文使用逻辑说明](USAGE.zh-CN.md)。

## 下载安装

在 [Releases](https://github.com/SteveWang92/NGUInjector-Chinese/releases) 页面下载 `NGUInjector-vX.Y.Z.zip`，不要下载 GitHub 自动生成的 Source code 压缩包。解压后目录结构如下：

```text
dist/
  inject.bat
  injector/
    NGUInjector.dll
    SharpMonoInjector.dll
    smi.exe
  sampleprofiles/
```

使用方法：

1. 在 Windows 上启动 Steam 版 NGU IDLE，并进入游戏。
2. 把发布包解压到一个全新的目录。
3. 运行 `dist/inject.bat`。
4. 注入成功后，游戏左上角会出现悬浮层，第一行为 `自动化 - 运行中` 或 `自动化 - 未运行`。
5. 按 `F1` 打开中文设置界面。

升级新版本时，先在设置界面的 **常规** 页勾选卸载按钮旁的确认框并点击 **卸载**，再运行新版本的 `inject.bat`。已注入的 `NGUInjector.dll` 无法直接覆盖，请解压到新目录。

## 配置目录

首次注入后，会自动创建配置目录：

```text
%UserProfile%\AppData\LocalLow\NGUInjector
```

常用文件：

- `settings.json`：注入器设置。所有选项都可以在 `F1` 设置界面中修改。
- `zoneOverrides.json`：覆盖黄金狙击使用的默认区域属性。
- `profiles/default.json`：默认分配配置，控制装备、能量、魔力、资源3、Wandoos、重生、胡子和掘金者等自动化。

日志目录：

- `logs/inject.log`：注入器通用日志。
- `logs/loot.log`：敌人掉落日志。
- `logs/combat.log`：战斗算法日志。
- `logs/pitspin.log`：钱坑、每日转盘、世界树收获结果，跨会话保留。
- `logs/cards.log`：卡牌打出和丢弃日志，跨会话保留。
- `logs/debug.log`：错误日志。设置界面打不开或配置不生效时先看这里。

保存 `settings.json`、`zoneOverrides.json` 或任意分配配置后，注入器会自动重新读取，不需要重启游戏。

## 设置界面

游戏内按 `F1` 打开设置界面。下列名称与界面上的文字一致。

### 常规

- **总开关**：关闭后禁用全部自动化。
- **禁用悬浮层**：隐藏游戏左上角的状态显示。
- **AP 商店免费**：游戏内 AP 商店的购买不再扣除 AP，仍要求当前 AP 足够支付价格。只修改本地存档，与 Steam 内购无关。
- **添加 AP**：把左侧输入的数量加到当前 AP。
- **钱坑运行模式**：自动向钱坑投入黄金，并通过重生最大化钱坑获得的等级。
- **自动挑战首领**：自动核爆或挑战首领。
- **自动购买能量/魔力/资源3**：按各自页面上的自定义购买数量，用经验自动购买。所有启用项的合计费用都够时一次性购买（包括冒险属性）。
- **自动购买冒险属性**：按“冒险属性”页的自定义购买数量，用经验自动购买。
- **自动购买消耗品**：自动购买分配配置要用但当前没有的消耗品，仅在 AP 足够时购买。
- **已在运行时也使用消耗品**：关闭时，如果某消耗品效果仍在持续，消耗品断点不会再使用它。
- **自动每日存档**：AP 奖励可领取时自动创建每日存档并领取 AP，文件名带有 `(NGU Injector)`。
- **打开设置文件夹**：打开存放设置、分配配置和日志的目录。
- **卸载**：勾选旁边的确认框后点击，从游戏中卸载注入器。

### 分配

- **分配配置**：列出 `profiles` 文件夹中的配置文件。**更改配置** 加载下拉框中选中的配置，**编辑** 用文本编辑器打开它，**打开配置文件夹** 打开 `profiles` 目录。
- **管理能量 / 管理魔力 / 管理资源3**：按当前分配配置的断点分配资源。
- **管理 Wandoos OS**：按断点切换 Wandoos 系统。
- **管理 NGU 难度**：按断点切换普通/邪恶/变态 NGU。
- **管理胡子**：按断点启用胡子。
- **管理掘金者**：按断点启用掘金者。
- **自动升级掘金者**：有黄金时自动升级最便宜的掘金者，不会把黄金花到钱坑阈值以下。
- **掘金者限制为 X 每秒黄金的 %**：掘金者花费占总每秒黄金的上限。
- **管理装备**：按断点换装。
- **管理消耗品**：按分配配置的消耗品断点使用药水、幸运符、麦高芬松饼等。
- **自动重生**：达到分配配置中的时间或条件后自动重生。
- **魔法**：
  - **切换自动魔法**：按下面三个阈值自动开关血之意面、增数加成和伪造黄金的自动施放。
  - **血之意面 %**、**增数加成**、**伪造黄金 %**：对应魔法自动施放到的阈值。
  - **施放血魔法**：自动施放血魔法，每 10 秒或重生时尝试一次。
  - **铁丸**、**麦高芬 α**、**麦高芬 β**：施放铁丸（属性加成）和麦高芬 α/β（等级加成）的阈值。
  - **重生时施放**：重生前若冷却和阈值满足，用全部血液施放勾选的魔法，优先级为麦高芬 β > 麦高芬 α > 铁丸，剩余血液施放增数加成。

### 世界树

- **管理世界树**：自动收获果实。收益更优时，会在未满级时提前收获麦高芬 β 果实和怪癖果实。
- **切换掘金者**：收获前启用 PP 和经验掘金者。
- **切换胡子**：收获前启用黄金胡子。
- **为世界树切换装备配置**：收获前装备下方列表中的物品。
- **激活果实**：重新激活尚未购买经验特权的果实。
- **切换所需最低果实等级**：低于该等级的果实收获时不换装。
- **立即收获全部**：勾选旁边的确认框后点击，立即换装并收获全部果实，适合手动重生前使用。

### 物品栏

- **管理物品栏**：启用后会自动执行：
  - 锁定一个 Boost 后，把同类 Boost 合并到它身上直到 100 级。
  - 合并已装备和背包中的物品以及麦高芬，优先合并等级最高、已锁定的物品。
  - 自动 Boost：依次处理优先 Boost 列表、已装备物品、背包中已锁定物品，最后投入魔方。
  - 购买了改进的战利品过滤器时，自动过滤满 100 级的物品。
  - 自动转换未锁定的吊坠、Looty 等可转换物品。
  - 背包中有锁定的任务物品时把同类合并到 100 级，否则自动上交任务物品。
- **管理 Boost 转换**：完成全部普通 100 级挑战后，根据目标物品计算所需 Boost 并自动切换转换类型。背包中有锁定且未满级的 Boost 时，先转换成该类型把它升到 100 级。`inject.log` 中会显示每小时平均 Boost 进度。
- **魔方 Boost 优先级**：
  - **无**：关闭 Boost 转换。
  - **平衡**：保持魔方的原始力量和韧性相等。
  - **软上限**：保持魔方力量和韧性占各自软上限的比例相等。
  - **力量** / **韧性**：只给魔方加力量或韧性。
- **偏好麦高芬**：施放麦高芬 β 或吃麦高芬 α 果实时，只装备选中的麦高芬，其余槽位留空；如果已买下 “wasn't so random” 许愿，则只把选中的麦高芬放在第一个槽位。
- **装备 Boost 优先级**：物品 Boost 的顺序，默认 `力量 > 韧性 > 特殊`。
- **优先 Boost**：优先 Boost 的物品列表，按列表顺序处理。
- **黑名单物品**：永不 Boost 或合并的物品。与优先列表冲突时以黑名单为准。
- **重置 Boost 平均值**：重置魔方/物品 Boost 的平均进度统计。

### 泰坦

- **管理泰坦**：启用泰坦自动战斗。
- **切换掘金者**：战斗前启用掉落率、冒险、PP 和经验掘金者。
- **切换胡子**：战斗前启用 Neckbeard、BEARd 和黄金胡子。
- **为泰坦切换装备配置**：自动击杀或挑战泰坦前装备下方列表中的物品。
- **要管理的泰坦**：勾选要挑战并换装的泰坦，**版本** 用于快速切换泰坦版本。
- **战斗模式**：
  - **待机**：留在区域中待机。沃尔德和教母在待机模式下总是改用进攻模式。
  - **狙击**：满血后开战，预施放增益并等所有技能冷却完毕，大量使用格挡和麻痹，谨慎使用野兽模式。
  - **防御**：约 80% 血量开战，不预施放增益，野兽模式用得比狙击稍多。
  - **进攻**：约 60% 血量开战，不预施放增益，只在特殊攻击或下一击可能致命时格挡，频繁使用野兽模式。
  - **自动击杀**：泰坦刷新前换装，但不前往泰坦区域；无法自动击杀选中的泰坦时会尝试降低版本。
- **野兽模式**：待机战斗中是否使用野兽模式。
- **定位沃尔德**：沃尔德躲起来时，跳转到它所在的菜单。

### 冒险

- **启用战斗**：前往目标区域并自动战斗。
- **战斗模式**：待机、狙击、防御、进攻、一击。前四种同泰坦页；**一击** 开启野兽模式后只用普通攻击，不使用增益。
- **野兽模式**：待机战斗中是否使用野兽模式。
- **目标区域**：自动战斗或狙击的目标区域。
- **仅首领**：只打首领，适合区域狙击。
- **允许自动降级**：目标区域未解锁时，先在当前已解锁的最高区域战斗。
- **按顺序刷未完成套装**：无视目标区域，按区域顺序刷第一个已解锁、套装尚未完成的区域；全部完成后使用当前已解锁的最高区域。
- **无尽之怒塔**（ITOPOD）：无视目标区域，在 ITOPOD 战斗。泰坦战斗优先级更高。其下的战斗模式、野兽模式只作用于 ITOPOD。
- **优化模式**：每 10 秒优化一次 ITOPOD 层数。
  - **禁用**：不调整层数，不干扰游戏内的 Lazy ITOPOD Shifter。
  - **默认**：行为接近 Lazy ITOPOD Shifter；手动战斗时按普通攻击计算。
  - **特权点**：换层时使用增益、强力攻击、穿刺攻击和终极攻击，最大化特权点（PP）。
  - **经验/任意点**：同上，但最大化经验和 AP（任意点）。
- **自动推进**：最高到达层低于最优层时尝试向上推进，失败后自动关闭。
- **区域 / 敌人**：在指定区域里把不想打的敌人加入黑名单。

### 黄金

- **启用黄金管理**：关闭后禁用所有黄金换装逻辑。
- **重新狙击时间**：重生进行到该时间后重新启用黄金狙击，建议设在高级训练完成之后，以便打到更高区域。
- **CBlock 模式**：每解锁一个新区域就自动黄金狙击一次，适合连续刷挑战（Challenge Block）时区域零散解锁的情况。
- **立即黄金狙击**：立即装备黄金配置，并根据区域属性和黄金配置下的攻防计算最佳区域狙击首领。
- **装备配置**：黄金换装使用的物品。
- **黄金狙击泰坦**：勾选需要黄金换装的泰坦，全部不勾则泰坦永不使用黄金配置。绿色表示该泰坦本轮已完成黄金狙击。
- **重置泰坦状态**：立即把所有泰坦的黄金狙击状态重置为未完成。

### 任务

- **自动任务**：自动上交任务，具体行为取决于下面两项。
- **允许主要任务**：任务银行中至少有一个任务时接取主要任务，并去对应区域手动刷物品。
- **任务银行满时开始主要任务**：任务银行满时接取主要任务并手动刷；其他情况接取次要任务。手动刷任务会在泰坦战斗时暂停，优先级高于普通冒险。
- **对主要任务使用黄油**：尝试对主要任务使用黄油。
- **手动次要任务**：次要任务也手动刷。
- **对次要任务使用黄油**：尝试对次要任务使用黄油。
- **跳过超过 50 件的次要任务**：跳过剩余需求超过 50 件的次要任务。例如进度 3/54 会跳过，4/54 不会。
- **到达阈值(%)时放弃次要任务换主要任务**：次要任务进度低于阈值时放弃，改接主要任务。
- **为任务切换装备配置**：手动刷任务时装备下方列表中的物品。
- **战斗模式 / 野兽模式**：手动刷任务时使用的战斗设置，选项同冒险页。

### 许愿

- **管理许愿**：按设置自动向许愿投入资源。
- **限制为 X 槽位**：最多同时投入的许愿数量。例如有 4 个槽位但只想用 2 个，就设为 2。
- **能量 % / 魔力 % / 资源3 %**：投入许愿的资源占总量的百分比，在启用的槽位间平分。
- **分配模式**：
  - **默认**：按许愿编号优先。
  - **最便宜**：优先完成所需资源最少的许愿。
  - **最快**：优先能最快完成的许愿。
  - **平衡**：有多个槽位时，一个槽位给最便宜且未拉黑的许愿，其余槽位给无法达到速度上限的最便宜许愿。
- **优先许愿**：优先占用槽位的许愿列表，剩余槽位按分配模式填充。
- **软优先级**：开启时，先按分配模式排序，平局时列表中靠前的许愿优先；关闭时，列表中的许愿无视分配模式直接优先。
- **许愿黑名单**：永不投入的许愿。与优先列表冲突时以黑名单为准。

### 钱坑

- **自动每日转盘**：自动转每日转盘，结果写入 `pitspin.log`。
- **自动钱坑**：黄金达到钱坑阈值后自动投入，结果写入 `pitspin.log`。
- **预测钱坑结果**：投入前读取下一次奖励并据此准备。例如奖励是小铁丸时启用血液掘金者并把魔力投入血仪式，奖励是小石榴时装备世界树配置。
- **从日托取出物品**：奖励是装备冲击波时，从日托取出冲击波物品，让更多物品吃到冲击波。需要开启预测。
- **钱坑阈值**：黄金达到该数量后才投入钱坑。
- **日托阈值 (%)**：日托进度已达到该百分比的物品不会被取出。设为 100% 则总是取出。
- **冲击波物品**：投入钱坑前装备的物品；开启预测时，只在奖励为装备冲击波时装备。
- **切换掘金者和胡子**：投入前按预测奖励启用黄金胡子和掘金者。

### 卡牌

- **管理蛋黄酱**：优先生产能尽快打出卡组第一张卡所需的蛋黄酱；没有卡牌时均衡生产。
- **自动打出卡牌**：打出未保护且不会被丢弃的卡牌。
- **打出已保护卡牌**：允许打出受保护卡牌。
- **排序卡牌**：按排序顺序整理卡牌。
- **排序顺序**：先按第一条规则排序，相同时再看下一条。可选规则：
  - **稀有度**（`RARITY`）、**阶层**（`TIER`）、**花费**（`COST`）：从高到低。
  - **已保护**（`PROTECTED`）：受保护的在前。
  - **变化**（`CHANGE`）：对总加成的实际提升，从高到低。
  - **价值**（`VALUE`）：变化除以花费。
  - **标准化价值**（`NORMALVALUE`）：按加成类型标准化后的价值。
  - **类型**（`TYPE:xxx`）：指定加成类型排在前面。
  - 带 `（升序）`（配置中为 `-ASC`）的规则反向排序。
- **自动丢弃卡牌**：按丢弃设置丢弃卡牌。
- **丢弃已保护卡牌**：允许按规则丢弃受保护卡牌；关闭时受保护卡牌永不丢弃。
- **丢弃设置**：按卡牌类型设置稀有度和花费阈值，不高于任一阈值的未保护卡牌会被丢弃。例如挂件卡稀有度设为“较好”、花费设为 2，则稀有度不高于“较好”或花费不超过 2 的未保护挂件卡都会被丢弃，“很好”且花费 3 的挂件卡会保留。

### 烹饪

- **管理烹饪**：自动优化烹饪效率。
- **为烹饪切换装备配置**：吃饭前装备下方列表中的物品。

## 分配配置

分配配置位于 `profiles` 文件夹，通过“重生时间断点”控制装备、能量、魔力、资源3、Wandoos、胡子、掘金者、消耗品和重生。示例配置在发布包的 `sampleprofiles` 文件夹。配置中的键名和优先级代码保持英文。

断点中的 `Time` 表示当前重生经过的秒数，也可以写成对象：

```json
"Time": {
  "h": 1,
  "m": 30,
  "s": 20
}
```

优先级可以追加百分比上限，例如：

```text
CAPRIT-0:30
```

表示尝试封顶第 0 个血仪式，但最多只投入当前上限的 30%。用于非封顶优先级时，表示限制为闲置资源的百分比。已达到目标值的项目不会再分配。

### 能量

```json
"Energy": [
  {
    "Time": 0,
    "Priorities": ["CAPNGU-0", "CAPWAN", "AT-1", "NGU-1"]
  }
]
```

优先级分为封顶和非封顶两类，带 `-X` 的编号从 0 开始。封顶优先级会尽量用闲置能量达到未来 10 秒内能 BB 的最高断点；非封顶优先级按数量平分闲置能量。多余的资源会顺延给后面的优先级。

常用能量优先级：

- `CAPNGU-X`（0-8）、`CAPALLNGU`：封顶指定/全部能量 NGU。

### 重生

简单重生时间：

```json
"RebirthTime": -1
```

`-1` 表示不自动重生；其他数值表示到达指定秒数后重生。

复杂重生断点：

```json
"Rebirth": [
  {
    "Type": "Time",
    "Time": { "h": 1, "m": 1 }
  },
  {
    "Type": "Number",
    "Time": { "m": 15 },
    "Target": 10000
  }
]
```

上例中，重生 15 分钟后若增数（Number）能变为原来的 10000 倍就重生，满 1 小时 1 分钟则无条件重生。多个断点先按时间、再按目标判断。

可用类型：

- `Time`：到达指定时间后重生。
- `Number`：增数将达到上次的 `Target` 倍时重生。
- `Bosses`：下一次重生能多击败 `Target` 个首领时重生。
- `Muffin`：围绕麦高芬松饼循环 24 小时与（24 小时 − `Target` 分钟）的重生，`Target` 为 1-60。正在挑战中、可进入配置中的挑战、未通过变态巨魔挑战 2、五点钟阴影特权或野兽肥料怪癖未满级、或没有松饼且无法购买时，退化为普通 24 小时重生。
- `TimeBalancedMuffin`：同 `Muffin`，但会把 `Target` 分钟加到 24 小时重生上，让每天的重生时间保持一致，`Target` 为 1-15。

### 挑战

可在重生配置中指定要进入的挑战，编号从 1 开始：

- `BASIC`：基础挑战
- `NOAUG`：无挂件挑战
- `24HR`：24 小时挑战
- `100LC`：100 级挑战
- `NOEC`：无装备挑战
- `TC`：巨魔挑战
- `NORB`：无重生挑战
- `LSC`：激光剑挑战
- `BLIND`：盲目挑战
- `NONGU`：无 NGU 挑战
- `NOTM`：无时间机器挑战

示例：

```json
"Challenges": ["BASIC-1", "BASIC-2", "TC-1", "NOEC-1"]
```

### 消耗品

```json
"Consumables": [
  {
    "Time": 0,
    "Items": ["EPOT-B", "MPOT-B"]
  }
]
```

消耗品代码：

- `EPOT-A/B/C`：能量药水 Alpha/Beta/Delta
- `MPOT-A/B/C`：魔力药水 Alpha/Beta/Delta
- `R3POT-A/B/C`：资源3药水 Alpha/Beta/Delta
- `EBARBAR`：能量棒棒
- `MBARBAR`：魔力棒棒
- `MUFFIN`：麦高芬松饼
- `LC`：幸运符
- `SLC`：超级幸运符
- `MAYO`：蛋黄酱灌注器

可追加数量，例如：

```text
EPOT-A:2
```

表示使用两个能量药水 Alpha。持续到下次重生的消耗品（Beta 药水和麦高芬松饼）会忽略数量，只使用一个。

注意：注入器无法跨会话记住消耗品是否已使用，也不知道你是否手动使用过。重启游戏、重新注入或重新加载配置后，当前断点会再次执行。注入器会按预计持续时间尽量补偿，但不会考虑手动使用、同一断点重复的消耗品、重叠断点，以及 Alpha 与 Delta 药水共用计时器的情况。

## 区域属性覆盖

黄金狙击按各区域所需属性计算最佳区域：达到手动阈值时不开快速战斗狙击首领，达到待机阈值时开快速战斗狙击，并始终关闭野兽模式。默认值见 [`defaultZoneStats.json`](NGUInjector/defaultZoneStats.json)，可在配置目录的 `zoneOverrides.json` 中覆盖。

## 快捷键与其他功能

- `F1`：打开设置界面。
- `F2`：全局启用/禁用自动化。
- `F3`：快速保存，并导出可载入 Gear Optimizer 的 `ngusav.es` JSON。
- `F5`：把当前装备 ID 写入日志并复制到剪贴板，方便粘贴到分配配置。
- `F7`：读取快速保存。

## 从源码编译

需要 Visual Studio 2022 或更高版本（含 .NET Framework 4.8 开发组件）。Unity 引用通过 NuGet 还原，`Assembly-CSharp.dll` 是游戏自带的副本，已随仓库提交。

```bat
MSBuild.exe /restore /p:Configuration=Release NGUInjector\NGUInjector.csproj
```

发布目录会生成到 `NGUInjector/bin/Release/dist`。
