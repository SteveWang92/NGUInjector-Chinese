## [4.2.0] - 2026-10-04

### Added

- "AP 商店免费" toggle makes every in-game AP shop purchase free.
- "添加 AP" button adds the entered amount to current AP.
- "按顺序刷未完成套装" adventure option farms the first unlocked zone whose gear set is incomplete.

### Changed

- Settings form uses 野兽模式, 魔方 and Boost terms consistently.
- "刷新 50 物品次要任务" quest option is now labelled "跳过超过 50 件的次要任务".
- Card sort option "普通价值" is now labelled "标准化价值".

### Fixed

- Documentation challenge example uses the valid `NOEC` code.
